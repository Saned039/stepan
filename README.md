# Гостевой дом у Степана — Краснолесье

Современный адаптивный сайт гостевого дома для GitHub Pages.

## Публикация
Сайт настроен на автоматическую публикацию через GitHub Actions после каждого изменения в ветке `main`.

Адрес сайта: https://saned039-creator.github.io/stepan/

## Что есть на сайте
- адаптивный дизайн для телефона и компьютера;
- первый экран с призывом к бронированию;
- описание дома и спальных мест;
- фотогалерея с увеличением;
- удобства, стоимость и условия размещения;
- форма запроса бронирования с проверкой дат;
- контакты, карта и ответы на частые вопросы.

## Бронирование
Форма отправляет запрос в настроенный webhook n8n. Заявка не означает автоматического подтверждения дат: хозяин должен связаться с гостем и подтвердить бронирование.

## Данные и фотографии
Информация о доме и фотографии взяты из публичного репозитория [Yumis84/guest-house-map](https://github.com/Yumis84/guest-house-map), из каталога `guest-houses.js` и `assets/stepan/`. Фотографии пока загружаются из исходного репозитория.

## Проверить перед полноценным запуском
1. Убедиться, что workflow n8n принимает запросы с GitHub Pages и возвращает JSON с `success: true`.
2. Отправить тестовую заявку и проверить, что она приходит хозяину.
3. Убедиться, что условия и цены актуальны.
